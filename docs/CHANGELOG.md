- 未登录点击保存自动进入登录，成功后恢复保存确认，取消 / 失败不丢匿名草稿，不自动上传。
- 按账号与匿名状态隔离标签页工作区，退出 / 过期 / 切号清理旧账号正文、编辑区、列表及历史；旧关联草稿先鉴权再恢复，拒绝旧响应和迟到 401 干扰新会话。

- 修复收藏文章在保存、API 读取和切换时把逐条释义语言全部强制改为英文的问题；保留中英混合、全中文或全英文，语言无关的规范化仅用于未保存比较。
- 按文章及内容 / 批注版本记住本标签页的阅读语言选择，切换文章及刷新不串用、不重置；有界存储不含正文或凭证，旧版丢失的显示选择不作猜测恢复。
- 补充保存 / 读取、旧客户端兼容、逐条语言恢复、版本失效与存储故障回归测试。

### 新增与改进

- Word 导入保留支持的正文字体、字号与效果、段落、列表及表格排版；受限 UTF-16 格式元数据贯通阅读、编辑、释义、历史、分账号草稿、私有保存 / 重开和 Word 导出，不再先转纯文本 reflow。
- AI 整理限定为段落空白调整，逐项验证原词、标点、大小写与水平空白，拒绝改写并保留原文与格式；保护表格单元格边界，整理后保持阅读起点。
- 新增 `bun run users` 终端管理，可直接查看用户、其文章列表和完整保存正文；明确确认并生成受限权限的一致性备份后，事务删除用户及其全部文章。只读查看、预览变化、取消、失败回滚与控制序列过滤均有回归验证，不新增公开管理 API。
- 会话绑定用户 ID 与邮箱；删除后及同邮箱重注册后旧会话失效，SQL 还阻止删除期间的在途保存写回数据。升级后旧版仅邮箱会话需重新登录，文章与草稿不删除。
- 消息便签下移 24px，最大宽度收紧至 320px，缩小正文 / 标题和留白；移除右上角 ×，保留整张点击、键盘关闭及 1.7 秒可暂停倒计时，长消息适配可用视口高度。

- 恢复工具栏按钮下方的双语悬停 / 聚焦介绍，支持 Esc、移入介绍继续阅读及滚动容器外定位；清空图标改为扫把。
- 释义方式从 AI 设置移入阅读功能栏，以单个胶带按钮循环切换；悬停 / 聚焦查看当前方式介绍，移除常驻操作 / 偏好说明，保留浏览器记忆与后续请求边界。
- 删除释义后保持删除模式；同一时间只选一个目标，点击其他批注只切换目标，再次点击同一条才删除，支持逐条继续删除及独立撤回。
- 纸色与浮雕纹理分离，以中性明暗柔光混合替代 70% 不透明覆盖色层，增强八种纸张在全部六种配色下的细节，保留原版和强制颜色支持。

- 实现阅读工具栏撤回 / 恢复、连续输入合并、有界工作副本历史及快捷键；整批 AI 结果原子撤回，防止取消后的迟到响应覆盖。
- 支持单纯 / 局部上下文 / 全文释义，默认改为局部上下文；未保存或无效偏好使用新默认，已有有效选择继续沿用。按词条位置及语境指纹隔离复用，明确上下文预算与费用边界，不保存参考原文。
- 中英文释义共用独立英式 IPA，贯通缓存、API、草稿、历史及 Word 导出；缺失 / 无效音标保留旧释义，不追加请求。
- 消息有效显示时长改为 1700ms，保留暂停与继续；分页上限改为 5000 Unicode 码点，以正文偏移恢复新旧草稿阅读位置。
- 增补模式、历史、音标、草稿迁移及接口兼容测试；补齐英文 README 与路线图实施决策。

## 2026-11-06

### 新增

- 按每条释义当前显示的语言导出整篇文章为纯白 Word 文档，在浏览器本地生成，不调用 AI、不上传正文。
- 首页和阅读页支持 English / 中文界面切换，默认英文，记住浏览器内的选择。
- 首页增加五步模拟使用指南，支持导入、AI 设置、整理、双语释义、翻页与保存演示；固定窗口高度，步骤区独立滚动。
- 增加八种阅读纸张纹理及本地偏好记忆，保留原本背景。
- 首页与阅读页共用青色书本标签页图标。
- 单次 AI 释义同时返回中英文，支持逐条本地切换、保存双语内容及设置新释义默认语言。
- 增加有界词典缓存、缺失词条解析、批量去重、主动刷新释义和 AI 用量统计。

### 改进

- 草稿恢复保留已保存文章身份、原保存基线与未保存修改，重新校验作者权限；关联确认失败时允许重试，不误存副本。
- 收藏白板采用带淡灰网格的二维画布，支持拖动、25%–200% 缩放、捏合、适配全部、复位与键盘导航。
- 精简白板装饰与控制区，保留两侧角贴、文章胶带及作者删除入口；网格随画布一起移动缩放。
- AI 标题兼容常见返回包装，必要时最多请求一次短标题修正，失败时保留手动输入及取消能力。
- AI 设置中的密钥操作合并为一行，默认释义语言与密钥草稿分开管理。
- 手册与 AI 起标题统一使用透明胶带进度条，区分真实进度与未知耗时循环，并支持减少动态效果和强制颜色模式。
- 阅读纸面与分页区在桌面居中、小屏恢复可用全宽；更新首页介绍和展示截图。
- 默认开放局域网访问；未设置端口时，开发使用 3000、生产使用 80。

### 修复

- 修复浏览器 `fetch` 因错误的 `this` 绑定而失败。
- 修复导入文章后默认跳至末页，首次导入改为从第一页开始。
- 防止取消释义后的迟到响应覆盖新任务或重置新任务的操作锁。
- 统一 Cookie 与服务端会话有效期为 24 小时，不因普通访问续期。
