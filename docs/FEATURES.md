# 功能说明

[项目介绍](../README.md) · [架构设计](ARCHITECTURE.md) · [API 说明](API.md) · [运行与部署](DEPLOYMENT.md) · [更新记录](../CHANGELOG.md)

本文描述当前可用功能与交互。实现细节见[架构设计](ARCHITECTURE.md)，历史改动见[更新记录](../CHANGELOG.md)。

## 1. 页面与阅读空间

- 首页 `/` 或 `/home.html` 为手账欢迎页，点击「Start a new page」进入 `/index.html` 阅读页。
- 首页使用三张胶带便签和本地阅读线稿；阅读页直接展示工具栏与文章，不保留宣传大标题或收藏侧栏。
- 顶栏、工具栏保留全宽与响应式边距；桌面阅读纸面及分页区占主区域 80% 并居中，700px 及以下恢复可用全宽。
- 顶栏提供 Logo 返回首页、界面语言、Saved articles、AI setup、Login / Account。
- 阅读工具固定两行：第一行 Read、Paste text / Edit page、Import Word、Tidy this page；第二行 Add definitions、Remove a note、Save article / Save changes、Export Word、Clear。选词时 Define selected 与 Refresh selected 加入第一行。
- 保存、收藏、删除与未保存确认、AI 设置、账号使用便签弹窗，不替换正文或编辑区。支持 Esc、遮罩关闭、Tab 焦点约束与关闭后焦点 / 光标恢复；收藏白板上的确认便签可叠放。
- 胶带按钮和批注保留半透明、细微反光及撕边效果，装饰不裁切点击区域、文字或焦点轮廓；支持减少动态效果与强制颜色模式。

## 2. 界面语言

- 首页与阅读页顶栏提供语言按钮：英文界面显示「中文」，中文界面显示「EN」。点击或 Tab + Enter / Space 即刻切换；首次访问默认英文，不根据浏览器语言自动改为中文。
- 选择保存在本浏览器 localStorage，首页、阅读页及同源标签页共用；刷新后恢复。存储被禁用时仍可在当前页面切换，刷新后回到英文。
- 切换覆盖首页、工具栏、分页与词数、背景选项、弹窗、表单校验、进度、常见接口错误和 AI 用量提示；已显示的提示同步更新，不刷新页面、不重发请求、不打断任务。
- **界面语言与释义语言独立**：不改写正文、保存的标题或输入内容，不改变页码、选词、草稿、API key、新释义默认语言或现有批注显示语言，也不会产生未保存修改。

## 3. 首页使用指南

- 点击语言按钮右侧的「amnual / 使用指南」打开五步模拟弹窗，依次体验导入文本、AI 设置、整理段落、选词与双语释义、翻页与保存；末步点击「完成演示」关闭。
- 可以编辑短示例、试用默认释义语言、点击批注切换中英文，以及更换示例纸张和字号；不加载完整阅读页。
- 手册不单独提供语言按钮，跟随首页及同源页面的语言更新，不重置当前步骤、输入或操作状态。
- 每步只展示模拟操作区，不显示额外步骤标题与介绍。窗口固定高 680px，小屏不超过视口安全高度；中间独立滚动，上下步按钮始终可见，语言和反馈变化不撑高窗口。
- 所有演示状态仅在内存中；只读演示密钥无需替换，不调用 AI、保存文章或写入真实设置。关闭后焦点返回入口，重新打开从第一步开始。

## 4. 粘贴、编辑与分页

- 没有正文时点击「Paste text」打开统一编辑区，再按 Ctrl/Cmd+V，点击「Reflow & start reading」完成导入。不请求剪贴板权限，也不会由按钮触发浏览器粘贴菜单。
- 有正文时同一按钮变为「Edit page」，可直接修改或粘贴到当前页，输入即时应用，保留文章关联，不会误新建文章。
- 导入以空行分段，合并段内错误断行，保留数字、标点和 Unicode 字符；阅读视图按独立 `<p>` 展示，只读并支持选词。
- 每页最多 **3000 个 Unicode 字符**，字母、数字、标点、空白、换行及 `『释义』` 标记全部计入。优先在段落、句子或空白处分页，所有分页拼接后与正文完全一致，不丢弃分隔符。
- 首次粘贴和 Word 导入从第一页开始；可用上一页、下一页和页码选择浏览。编辑溢出时向后分流并跟随光标，删除内容后重新分页。
- 整篇正文上限 **100000 个 UTF-16 单元**，与后端校验一致；超限报错并保留原文章，不截断。

### Word 导入

- 「Import Word」支持 `.docx`，最大 **5 MB**，在浏览器本地解压和提取正文，再合并断行、保留段落并分页。
- 不导入图片和 Word 样式。扫描图像、旧 `.doc`、加密或损坏文件会明确提示，不改动已有正文；旧 `.doc` 请先另存为 `.docx`。
- 解压与 XML 提取有额外安全限制，导入无需上传文件。

### 草稿与阅读记录

- 当前标签页自动保存全部正文、分页位置、双语批注、每条显示语言、已保存文章 ID、保存基线和未保存修改；刷新或从首页返回后恢复。
- 恢复已保存文章时重新确认服务端记录及当前账号权限。自己的文章继续使用 Save changes 更新原记录；他人的文章只能另存副本。
- 关联确认失败时保留正文并显示 Retry saved article，避免网络错误导致误存副本；原记录已删除时保留为未保存草稿。
- 旧工作记录没有文章 ID 时仍作为草稿恢复；从收藏重新打开原文章一次即可建立关联。
- 草稿保存在 sessionStorage，不是永久备份；关闭标签页后会失去临时记录。存储被禁用时明确提示。

### 阅读纸张

- 顶部分页栏 Next 右侧提供「Background」，打开原生单选预览窗口。
- 「原本」保持原始笔记本背景不变；其余旧纹理全部重建，按实物参考提供莱尼纸、艺术纹理纸、雅纹纸、皮纹纸、大地纸、牛皮纸、云龙纸与棉纸。
- 八种新纸面统一使用水灰色，仅通过细织纹、不规则压纹、横向细纹、皮革颗粒、植物碎纤维、粗纸浆、长纤维和云絮起伏区分材质，不保留旧版的米黄、棕色、菱形或装饰波纹。
- 纹理由本地 SVG 纤维高度图与明暗浮雕生成，预览和阅读纸面共用同一资源及纹理尺度；不直接使用参考照片、不含照片文字，也不请求外部图片。原有纸张偏好继续有效，选择原本可恢复无新纹理的纸面。
- 选择立即应用，不改变正文、分页、释义或保存状态；支持方向键选择、Esc / 遮罩关闭与焦点恢复。
- 偏好保存在浏览器 localStorage，不上传账号或文章；未知值回退原本。存储被禁用时仍可切换，并提示仅本页有效。

## 5. AI 整理当前页

- 点击「Tidy this page」仅将当前页发送到 DeepSeek，要求合并错误断行、统一段落空行、修正标点空格，并保留事实、数字和单词，不主动改写内容。
- 输出必须是纯文本，不含说明或 Markdown。只替换当前页对应区间，保留页边界空白与其他正文，然后重新分页。
- 已含批注的当前页不执行排版，提示先整理、再添加释义，避免移动已有注释。
- 任务期间锁定冲突操作；失败给出具体提示，不用临时标记污染正文。

## 6. 双语释义与选词

1. 点击「Add definitions」进入选词模式，单击单词选中并高亮，再次单击取消。
2. 连续且仅以空白分隔的同段单词合并为短语；不相邻片段分别解释，不跨标点、批注或段落合并。
3. 点击「Define selected (数量)」执行释义，待处理单词显示点状下划线，状态栏反馈进度，不往正文插入占位文本。
4. 每批一次请求同时返回英文和对应中文；两种语言均校验成功后，按正文偏移插入或更新 `『英文释义』` 并关联中文，随后重新分页。
5. 完成后清除选词高亮，由胶带批注取代。Read 模式点击批注或 Tab + Enter / Space 即刻切换中英文，不请求 AI、不需要密钥，各条批注互不影响。

示例：

```text
apple『a round fruit with red or green skin』
take off『to leave the ground and begin to fly』
The quick『fast』 brown fox jumps over the lazy『slow-moving』 dog.
```

- 新批注默认显示英文，可在 AI setup 的 Zh / Eng 设置中修改后续新释义默认语言；不重置现有批注。
- 正文始终保留英文批注，中文作为附加数据保存；本地切换不改变分页或未保存状态。中英文内容随文章保存，其他读者首次打开仍默认英文；新增或修改释义需要保存。
- 旧文章只有英文时仍可阅读，点击仅提示重新生成双语释义，不悄悄请求翻译；重新释义替换旧注释，不重复叠加。
- Add definitions 进入后仍保留原名称，重复点击不退出或清空选词。点击 Read 或按 Esc 返回普通阅读并清理临时选词 / 删除状态，保留已有批注。
- 释义进行中仍可 Read / Esc 中止请求并释放操作锁；取消后的迟到结果不写正文或缓存，也不影响后续新任务。
- 选词模式点击旧批注不会切换语言；长释义按行续贴胶带，不裁切文字或焦点轮廓。

### 复用、刷新与失败处理

- Define selected 先保留已有完整双语注释，再查询缓存，只请求缺失词条；相同词组在同批去重，一条结果可回填多个位置，不混淆 `US` 与 `us`。
- 缓存是通用词典释义，不额外发送全文或上下文；只保存查询词和双语结果，包含模型 / 提示词版本，最多 **256 条、7 天有效**，按最近最少使用淘汰。存储禁用时降级内存。
- 「Refresh selected」明确绕过已有释义和缓存重新请求，同批仍去重；不会自动刷新。批注可保留 `term` 查询身份，旧注释不猜测来源来填充共享缓存。
- 提示词要求英文最多 20 个单词、中文最多 20 个字符；AI 响应校验兼容较长旧结果，每种语言 600 字符技术上限，不静默截断。每批最多 12 个不同词组，并按输入长度与输出预算分批。
- 只接受本批请求过且双语完整的结果，部分失败仍保留有效词条。下次选择缺失项即可重试，不自动重发或继续后续批次。
- `finish_reason=length` 时仅恢复完整闭合且校验通过的 JSON 词条，不猜测截断内容。

### 删除注释

- 点击「Remove a note」进入删除模式，按钮变为危险色。
- 第一次点击批注选中整条胶带，显示浅玫瑰色与虚线轮廓；再次点击同一条才删除，恢复无该注释的正文，并同步移除中文数据。
- 再次点击 Remove a note 或回到 Read 可退出删除模式。

## 7. AI 设置与用量

- 点击「AI setup」在手写横线上输入 DeepSeek API key，选择「Keep for this tab」后才确认生效并保留到当前标签页 sessionStorage。刷新可恢复，关闭标签页后清除。
- 关闭按钮、遮罩或 Esc 会丢弃未确认草稿，继续使用原密钥；Show key、Forget key、Keep for this tab 共用一行，可显示或立即清除已确认密钥。
- 密钥不使用 Cookie，不随本地 API 请求传输，不上传本应用服务器或数据库，仅用于浏览器直连 DeepSeek。存储受限时已确认密钥仍可用于当前页面。
- Zh / Eng 即刻切换新释义默认语言，用下划线标记；偏好单独存在 localStorage，不请求 AI，不确认密钥草稿，也不改变已有注释或界面语言。
- 未配置密钥时，排版 / 释义会打开设置；留空标题保存则在保存便签提示手动输入标题，不打断保存流程。设置本身不发送 AI 请求，释义或缓存命中也不需要密钥。
- 「Usage & dictionary cache」显示本标签页请求次数、接口实际报告的输入 / 输出 token 和服务端缓存命中 token。统计不含密钥、提示词或正文；没有 usage、失败或中止的请求标为未知，不当作零消费，不估算账单金额。
- 可清除词典查询缓存，不删除文章批注或 API key。密钥无效、网络、超时或配额问题会明确提示，不自动更换模型或增加付费重试。参数细节见 [API 说明](API.md)。

## 8. 保存文章与 AI 标题

- 保存需要登录。Save article 保存整篇正文的全部分页、批注与双语数据到 SQLite，不只是当前屏幕上的一页。
- 新文章打开保存便签输入英文标题；标题不允许中文，限制 **1–20 个字符（含空格，不是 20 个单词）**，前后端均校验。
- 已选本人文章使用 Save changes，确认后保留原标题并更新内容；他人文章和无作者历史文章保存为自己的新副本。
- 首次导入、Word 导入和清空重置原文章选中项；正常 Edit page 修改或粘贴不重置。
- 新标题可以留空，由本标签页已确认的 DeepSeek 密钥概括**整篇文章**，成功后再保存。兼容 JSON、纯文本、引号、常见前缀和 Markdown 包装；结果不合规时最多请求一次更短标题，不静默截断。
- 未配置密钥、网络 / 鉴权 / 配额 / 超时失败，或两次输出仍无效时，停止动画并提示手动输入，不生成兜底标题、不写数据库。连接或鉴权失败不按格式问题重试。
- 起名期间显示透明胶带循环，可取消 / Esc / 遮罩中止并释放锁；迟到结果不保存。已经发出的数据库写入不会因为关闭便签而被宣称回滚。

## 9. 收藏白板

- 顶栏「Saved articles」打开略微倾斜的白色收藏板，桌面最大宽 1080px，两侧胶带固定边框，正文仍保留在后方。
- 所有公开文章以紧凑透明胶带显示标题与日期，长标题换行；当前文章有下划线和勾号标记。
- 文章放在淡灰网格二维画布中，不采用上下滚动列表。鼠标 / 单指拖动平移，滚轮 / 双指捏合缩放，网格、文章和删除按钮同步移动；拖动结束不会误触打开或删除。
- 缩放范围 **25%–200%**，右下角保留 Fit all 和 Reset 100%，当前比例供屏幕阅读器播报；首次打开适配文章，刷新和重开保留本页视角。
- 画布聚焦后方向键平移、`+` / `−` 缩放、`0` 复位、`F` 适配；键盘聚焦屏幕外文章时自动移入可见区域。
- 点击标题加载整篇正文与释义并关闭白板；有未保存修改时叠放确认便签，取消则保留白板和草稿。
- 作者文章右上角的「×」经确认后删除整篇保存记录；白板保持打开并修复焦点。删除当前文章时取消关联，但保留阅读区正文；他人和无作者历史文章不显示删除入口。
- 「↻」重新拉取列表。网格只作装饰，不拦截操作，强制颜色模式下隐藏。

## 10. Word 导出

- 「Export Word / 导出 Word」在浏览器本地下载整篇 `.docx`，包含全部分页和已有释义；无需登录、保存、API key 或 AI 请求，不上传正文。
- 每条释义按其**当前显示语言**导出，允许同一文档中英文混合；即使英文释义相同也逐条独立处理。只有英文的旧批注保留英文，未注释正文原样保留。
- 输出纯白 A4 纸面、黑色文字，无阅读纹理、胶带、批注底色或网页工具栏；释义以内联 `『释义内容』` 展示，保留段落、换行和制表符，由 Word 自然分页，不复制网页的 3000 字符边界。
- 已选文章使用原标题作为文档标题和文件名；未保存文章默认 `EngNote.docx`，不调用 AI 起名，文件名移除不安全字符。
- 空文章或 AI / 导入任务进行时禁用按钮；失败给出可重试提示。导出只读快照，不改变阅读位置、释义选择、草稿、保存状态、密钥或纸张。

## 11. 邮箱账号与验证码邮件

- 顶栏 Login 打开账号便签，在窗口内切换登录与注册，校验错误显示在便签内，不影响正文或未保存编辑。
- 注册使用邮箱、六位验证码和 **6–128 字符密码**。Send Code 通过 SMTP 发送验证码，有效期 **5 分钟**，同邮箱重新获取需等待 **60 秒**。
- 验证码邮件为水灰背景、米白便签、鼠尾草绿胶带，突出可复制六位数字、真实有效期及安全提醒；同时提供 HTML 和纯文本，不依赖外部资源，不涉及手机短信。
- 当前邮件引导文案为「让读英文简单一点」「开始你的收藏。」及「欢迎来到 EngNote。在注册窗口输入下方验证码，开启新的英文之旅。」，模板见 [`backend/verificationEmail.ts`](../backend/verificationEmail.ts)。
- 注册成功后回到登录，登录只需邮箱和密码，无需验证码。密码以 Argon2id 慢哈希入库，不存明文。
- 登录后显示 Account，便签显示邮箱与 Logout；退出后恢复登录表单。Cookie 和服务端会话统一 **24 小时**，到期需重新登录，不因访问续期。
- 未登录可阅读、粘贴、导入、使用自己的 AI 密钥和导出，但不能保存、覆盖或删除文章；后端独立校验会话和作者。
- **收藏是公开阅读书架，不是私密笔记**。会话 Cookie 自动随请求携带，前端不可读取 Token；写请求校验同源，接口不公开作者邮箱。

## 12. 进度与可访问性

- 手册的确定进度和 AI 起标题的未知耗时共用透明胶带逐渐贴上、前缘轻微翘起的样式，不使用普通细线条，不伪造百分比。
- 已知进度提供真实的无障碍数值；未知耗时保持循环和状态文字。减少动态效果时使用静态胶带，强制颜色模式保留可识别状态。
- 组件结构、样式入口及后续开发要求见[架构设计](ARCHITECTURE.md)和 [AGENTS.md](../AGENTS.md)。
