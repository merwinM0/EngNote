# EngNote 英文阅读助手

**让读英文简单一点。**

EngNote 是一个基于 **HTML + TypeScript + CSS + Bun** 的英文阅读网页应用。把文章粘贴进来，或导入 Word，在清爽的笔记纸上阅读；用 AI 整理段落、为单词和短语添加中英文释义，再把值得保留的文章存进收藏。

![EngNote 首页预览](./home.png)

## 核心亮点

- **专注阅读**：水灰手账风、胶带便签与多种阅读纸张，适配电脑和手机；提供五档阅读字号，释义与原文同字号显示。
- **导入与编辑**：支持粘贴和本地 `.docx` 导入，保留支持的正文字体、字体效果、段落、列表与表格排版；每页最多 5000 个 Unicode 字符，实时编辑、自动分页并恢复当前标签页的阅读草稿。
- **本地单词搜索**：背景按钮旁可切换全文 / 本页模糊搜索；重复词按位置逐条列出，显示简洁页数和前后距离，点击定位并显示 1.3 秒纯边框，悬停查看该处已有释义，不调用 AI 或上传查询。
- **按需理解**：通过 DeepSeek 仅整理当前页段落，不改写词句与标点；为选中的单词或短语一次生成共用英式音标的中英文释义，在功能栏选择单纯、局部上下文或全文参考（默认局部上下文），悬停查看介绍；阅读时点击批注即可切换语言，保存与重新打开均保留逐条语言选择，支持中英混合，不额外请求 AI。
- **释义清单**：在便签弹窗中以透明胶带展示释义；字符计数左侧查看本篇全部分页的「单词 / 短语 + 释义」，点击切换中英文；顶栏查看账号私有、数据库永久保存的跨文章去重清单，支持筛选与分页，不影响 AI 设置里的临时词典缓存。
- **撤回与恢复**：正文编辑、AI 整理和批注操作支持有界历史及快捷键；删除释义采用单目标两次确认，删除后可继续操作；导入、清空和切换文章隔离历史。
- **减少重复请求**：复用已有释义和有界词典缓存，支持主动刷新释义与查看 AI 用量。
- **保存与导出**：邮箱注册、登录后保存整篇文章；已保存文章新增或刷新释义后自动保存修改，无需再次确认，收藏按最近保存 / 修改优先排列，可拖动缩放管理；也可按每条批注当前显示的语言导出 Word，保留支持的原文排版与字体，纸面保持纯白。
- **双语界面**：默认英文，可随时切换中文；界面语言和释义语言互不影响。
- **本机终端管理**：简洁边框展示用户与文章，支持只读 `--json` 输出；明确确认并生成备份后，可删除用户及其全部文章和词汇清单，不提供公开管理接口。

> **使用边界**：已保存文章为账号私有，只有本人能查看、修改或删除，不支持共享。无需账号即可阅读、编辑、导入、使用自己的 AI 密钥和导出 Word，工作草稿保留在当前浏览器标签页；首次保存文章仍需登录并确认，不自动上传新草稿；已登录且已关联本人保存文章时，释义完成后自动更新原文章。DeepSeek API key 仅保留在当前标签页，请求直连 DeepSeek，不上传到本应用后端。登录后新生成或刷新的释义会单独收录到永久词汇清单，不自动上传未保存文章的正文；匿名已有释义可在登录后明确点击「收录本篇释义」，或确认保存文章时收录。

## 快速开始

### 环境要求

- Bun **1.3.14**（项目已验证版本）。
- 本地开发可不配置 SMTP 或 Redis；生产环境的邮箱验证码与会话需要可用的 **SMTP 和 Redis**。

在项目根目录运行：

```bash
bun install --frozen-lockfile
test -f .env || cp .env.example .env
bun dev
```

打开 <http://localhost:3000>。首页位于 `/`，点击「Start a new page」进入 `/index.html` 阅读页。

启动面板仅展示 localhost 地址、PID、Bun 版本与运行模式，不枚举局域网地址；`bun dev --json` 可输出结构化启动记录。默认仍监听 `0.0.0.0`，同网段设备可通过本机局域网 IP 访问；如需仅本机访问，在 `.env` 中设置 `HOST=127.0.0.1`。未设置 `PORT` 时，开发模式使用 **3000**，生产模式使用 **80**。

首次使用可打开首页的「amnual / 使用指南」体验五步模拟操作，不需要真实 API key，也不会调用 AI 或保存文章。

## 技术栈

| 层 | 技术 |
| --- | --- |
| 前端 | 语义化 HTML、TypeScript、原生 DOM、CSS，无 UI 框架 |
| 运行与构建 | Bun 源码运行、原生 HTML 打包与开发热更新 |
| AI | DeepSeek `deepseek-chat`，OpenAI 兼容接口 |
| 持久化与认证 | SQLite、Argon2id 密码哈希、Redis 验证码与会话 |
| 邮件与 Word | Nodemailer + SMTP；`fflate` 本地解压与生成 `.docx` |

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `bun dev` | 开发模式运行源码，前端热更新、后端文件变化后重启 |
| `bun start` | 生产模式运行源码，关闭 HMR |
| `bun run typecheck` | 检查前后端 TypeScript 类型 |
| `bun test` | 运行单元与接口测试 |
| `bun run build` | 导出前端检查产物到 `dist/`，不是完整应用的部署包 |
| `bun run users` | 终端查看用户 / 文章，备份并确认级联删除；[命令与恢复说明](docs/DEPLOYMENT.md#9-终端用户与文章管理) |

应用通过 Bun 后端提供数据库和认证能力，不能只部署 `dist/`。生产配置、反向代理和备份说明见[运行与部署](docs/DEPLOYMENT.md)。
